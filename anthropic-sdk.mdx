Impala serves **`/v1/messages`**, the Anthropic Messages API, alongside its OpenAI-compatible endpoints. Anthropic-format tooling talks to Impala directly — no proxy, no translation layer, no code changes.

That covers the Anthropic SDKs, the **Claude Agent SDK**, and **Claude Code**.

## What you need

- `BASE_URL` — your Impala endpoint
- `API_KEY` — your Impala key
- `MODEL` — the model your endpoint serves

<Info>
  The Anthropic SDKs append `/v1/messages` to whatever base URL you give them. Pass the host root, not a URL that already ends in `/v1`.
</Info>

***

## Anthropic SDK

Point `base_url` at Impala and use your Impala key:

```python
import anthropic

client = anthropic.Anthropic(
    base_url="<BASE_URL>",
    api_key="<API_KEY>",
)

message = client.messages.create(
    model="<MODEL>",
    max_tokens=256,
    messages=[{"role": "user", "content": "Summarize this ticket in one line."}],
)
print(message.content[0].text)
```

TypeScript is the same shape:

```javascript
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic({
  baseURL: process.env.BASE_URL,
  apiKey: process.env.API_KEY,
});

const message = await client.messages.create({
  model: process.env.MODEL,
  max_tokens: 256,
  messages: [{ role: "user", content: "Summarize this ticket in one line." }],
});
```

Or directly:

```bash
curl -X POST "$BASE_URL/v1/messages" \
  -H "content-type: application/json" \
  -H "x-api-key: $API_KEY" \
  -d '{
    "model": "'"$MODEL"'",
    "max_tokens": 256,
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

## Claude Agent SDK

The Agent SDK reads the standard Anthropic environment variables, so it needs no code change:

```bash
export ANTHROPIC_BASE_URL="<BASE_URL>"
export ANTHROPIC_AUTH_TOKEN="<API_KEY>"
export ANTHROPIC_MODEL="<MODEL>"
```

Then run your agent as usual. Tool calling works as it does against any Messages API endpoint — the SDK sends Anthropic-format tool definitions and Impala serves them.

## Claude Code

Same variables, then launch:

```bash
export ANTHROPIC_BASE_URL="<BASE_URL>"
export ANTHROPIC_AUTH_TOKEN="<API_KEY>"
export ANTHROPIC_MODEL="<MODEL>"
claude
```

Export them in the same shell you launch from.

***

## Things to know

**Set `ANTHROPIC_MODEL` explicitly.** Clients that discover available models at startup expect Anthropic's own catalog. Naming the model yourself avoids that lookup entirely.

**Raise your timeouts.** A call takes seconds and can take minutes under load, and an agent making many sequential turns multiplies that. Raise the timeout in whatever runs your agent and keep turn counts low — see [Building for async inference](/async-inference).

**This path is per-request, not batched.** That's the right shape for an agent loop, where each turn depends on the last. Where a piece of the work is a rollout over a fixed input set — an eval sweep, a replay — that part is cheaper as a [batch](/run-your-first-batch).

## When you'd still want a gateway

Nothing here requires a proxy. You'd add one for reasons of your own: routing across several providers, keeping the Impala key out of client environments, or central budget and rate controls. See [LiteLLM](/connect-litellm) if that's what you're building.
