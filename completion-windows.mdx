Every request runs in a **completion window**. Windows that return sooner cost more, and windows with more time to finish cost less. The model and its output are the same in every window, so the cheapest window your workload can wait for is usually the right one. [Run async and open source](/async-inference) explains why waiting costs less.

From fastest to lowest cost, the windows are `asap`, `standard`, `flex` and `batch`. Requests that don't set a window run in `standard`. Each request is billed at its window's rate; see [Pricing](/pricing).
