Impala serves `POST /chat/completions` in the OpenAI format. If you have OpenAI code, the change is the base URL, the key, and the model name — see [Quickstart](/impala-cloud-setup) for those three values.

This is the endpoint behind agent loops and anything else that needs a response per request rather than a file of results.

## The request

`model` and `messages` are the only required fields.

```python
resp = client.chat.completions.create(
    model="<MODEL>",
    messages=[{"role": "user", "content": "Summarize this ticket in one line."}],
)
print(resp.choices[0].message.content)
```

`messages` is the standard OpenAI chat format. A `system` message sets behavior, `user` carries the prompt, and `assistant` carries prior model turns when you're replaying a conversation:

```python
messages=[
    {"role": "system", "content": "You are a concise assistant."},
    {"role": "user", "content": "What changed in this diff?"},
    {"role": "assistant", "content": "Two functions were renamed."},
    {"role": "user", "content": "Which ones?"},
]
```

`base_url` routes your requests to Impala instead of `api.openai.com`. Pass it exactly as provided — endpoints differ between accounts. `model` names the model your endpoint is provisioned for.

## Timeouts and retries

Two settings matter more here than at an interactive provider.

**Raise your timeouts.** A call takes seconds, and minutes under load. SDK defaults are tuned for interactive providers and will abort a request that would have succeeded.

**Turn off automatic retries.** Retrying a request that is already queued adds load to the fleet without shortening your wait.

```python
client = OpenAI(
    base_url="<BASE_URL>",
    api_key="<API_KEY>",
    timeout=600.0,
    max_retries=0,
)
```

For an agent, total time is per-step time multiplied by the number of steps, so turn count is usually a bigger lever than any individual call. See [Run async and open source](/async-inference).

## Streaming

Set `stream=True` and iterate. Streaming doesn't make the work finish sooner, but it gets tokens moving rather than leaving the connection silent:

```python
stream = client.chat.completions.create(
    model="<MODEL>",
    messages=[{"role": "user", "content": "Write a haiku about batch inference."}],
    stream=True,
)

for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)
```

## Keep the key out of your source

The OpenAI SDK reads these environment variables automatically:

```bash
export OPENAI_BASE_URL="<BASE_URL>"
export OPENAI_API_KEY="<API_KEY>"
```

Which lets your code drop the explicit arguments:

```python
from openai import OpenAI

client = OpenAI()  # reads OPENAI_BASE_URL and OPENAI_API_KEY

resp = client.chat.completions.create(
    model="<MODEL>",
    messages=[{"role": "user", "content": "Ping"}],
)
```

Don't commit your key or share it outside your team. Ask us to rotate it any time.
