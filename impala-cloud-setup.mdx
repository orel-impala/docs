## 1. Get your endpoint

Sign up at [platform.getimpala.ai](https://platform.getimpala.ai) to get a serverless endpoint. New accounts are reviewed before they are activated, so if you need it sooner, talk to your Impala contact.

| Value | What it is |
| --- | --- |
| `BASE_URL` | Your inference endpoint |
| `MODEL` | The model your endpoint serves |

Both come from Impala. If you cannot find them, ask your Impala contact.

## 2. Create an API key

Create a key in **Settings** on [platform.getimpala.ai](https://platform.getimpala.ai), and send it as a bearer token on every request.

## 3. Point your client at Impala

The endpoint is OpenAI-compatible, so the change is the base URL, the key, and the model name.

<CodeGroup>

```python Python
from openai import OpenAI

client = OpenAI(
    base_url="<BASE_URL>",
    api_key="<API_KEY>",
    timeout=600.0,
)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "<BASE_URL>",
  apiKey: "<API_KEY>",
  timeout: 600_000,
});
```

```bash Environment
export OPENAI_BASE_URL="<BASE_URL>"
export OPENAI_API_KEY="<API_KEY>"
```

</CodeGroup>

The long timeout is deliberate. SDK defaults are tuned for interactive providers and will abort early — see [Cheaper inference, better quality](/async-inference).

## 4. Confirm it works

```bash
curl "$BASE_URL/chat/completions" \
  -H "Authorization: Bearer $IMPALA_API_KEY" \
  -H "Content-Type: application/json" \
  --max-time 600 \
  -d '{
    "model": "'"$MODEL"'",
    "messages": [{"role": "user", "content": "What is 17 times 3?"}]
  }'
```

A response with no error means your endpoint, key and model are working end to end.
