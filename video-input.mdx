Vision-language models on Impala accept video as input. Send it as a reference to an object in S3, or inline as base64. The request format is the same as vLLM's video input.

The inference engine splits the video into frames and encodes them with the prompt. You can set the frame rate per request with `mm_processor_kwargs`:

```json
{"mm_processor_kwargs": {"fps": 2}}
```
